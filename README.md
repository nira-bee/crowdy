# Crowdy

Event discovery and community platform — find and join local events and group gatherings based on shared interests and location.

## Tech Stack

- **Frontend**: Expo / React Native (iOS, Android, Web)
- **Backend**: Spring Boot (Java 21)
- **Database**: PostgreSQL 16 + PostGIS, Redis 7, S3
